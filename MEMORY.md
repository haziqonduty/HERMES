## Mistakes & lessons
- 2026-10-31 — supabase-js `.rpc(...).returns<T[]>()` mistypes set-returning functions ("Cannot cast single object to array type") — cast the data instead.
- 2026-10-31 — Server components can't sign a user out (cookies are read-only in render): redirect to a route handler (`/logout`) that calls `signOut()` and redirects.
- 2026-10-31 — PGlite tests: JSON.stringify of a Postgres `infinity` timestamp prints null (Invalid Date) — not a bug. To test RLS, `set role authenticated` after granting table privileges (superuser bypasses RLS).
- 2026-10-27 — **Validate SQL locally with PGlite** before handing migrations to the user: scratchpad `pg/run.mjs` (npm `@electric-sql/pglite@0.2.17`) stubs `auth` schema/`auth.uid()`/roles and runs every migration + seed in order. Caught nothing this time but proves the chain; also use it to test triggers.
- 2026-10-27 — A table CHECK (e.g. `quantity >= 0`) fires before an AFTER-trigger's own check, so pre-check with `select … for update` and raise a friendly exception first.
- 2026-10-27 — Node 24 runs `.ts` files directly (type stripping) — handy for quick unit checks of pure lib functions (copy into scratchpad, `node file.ts`).
- 2026-10-27 — New routes give TS errors on `PageProps<"/route">` until `npx next typegen` runs (build does it automatically).
- 2026-10-27 — Don't define a component inside a component's render (react lint); pass flags (e.g. `compact`) to a top-level helper instead.
- 2026-10-27 — ESLint here enforces React purity in server components too: no `Date.now()` in render (use one `const now = new Date()`), and no reassigning a `let` inside `.map` (react-hooks/immutability) — compute with reduce/slice instead.
- 2026-10-27 — Page files can't export extra components (Next type check) — put shared bits like SetupNotice in their own file.
- 2026-10-27 — After deleting a temporary test page, delete `.next/dev` before `npm run build` or stale route types fail the build.
- 2026-10-27 — New DB columns must not be added to selects on EXISTING pages until the user confirms the migration — otherwise those pages break in production. Keep new columns to new pages, or degrade gracefully (error code 42703 = undefined column).
- 2026-10-27 — Charts at half width: use a smaller SVG viewBox width (~420) so axis text isn't tiny, and thin x labels to ~6.
- 2026-10-27 — Long inline `python - <<'EOF'` heredocs in the Bash tool can fail to parse ("unexpected EOF while looking for matching `'`") when the script contains backticks/quotes. Write the script to the scratchpad with Write, then run it.
- 2026-10-27 — Stopping the dev server: broad `Stop-Process` over all node processes was blocked. Find the PID with `netstat -ano | grep :<port>` and `taskkill //PID <pid> //T //F`.
- 2026-10-27 — Table cells: put `whitespace-nowrap` on dates and a `min-w-*` on free-text columns, or dates wrap and text squashes.
- 2026-10-27 — Next.js 16 here has **Cache Components on by default**: any `cookies()`/`searchParams`/DB read or `usePathname`/`useSearchParams` on a dynamic route must sit inside `<Suspense>`, else the build fails. Pattern used: layout shell is static; user info + `{children}` stream in Suspense; dynamic `[module]` route uses `generateStaticParams`. Always run `npm run build` before committing.
- 2026-10-27 — `middleware.ts` is now `proxy.ts` (export `proxy`).
- 2026-10-27 — `usePathname()` on a dynamic route also needs Suspense under Cache Components; sidebar uses a `WithPathname` render-prop wrapper with an unhighlighted fallback.
