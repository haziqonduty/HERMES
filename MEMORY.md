## Mistakes & lessons
- 2026-10-31 — JS `Date.parse("2024-02-30")` is valid (rolls over). Validate dates by round-trip: `new Date(v+"T00:00:00Z").toISOString().startsWith(v)`.
- 2026-10-31 — After deleting a temporary preview page, `tsc` fails on stale `.next/types` until `npm run build` regenerates them — run build before tsc.
- 2026-10-31 — PGlite tests: seed data reuses `task_ref` across engines, so `order by task_ref limit 1` picks a different row each query. Capture the id once into a JS variable.
- 2026-10-31 — Phone screenshots: Edge CLI `--headless --window-size=390,…` silently renders at ~500px min width (crops the right side). Use `scratchpad/shots` (npm `playwright-core@1.55.0`, `chromium.launch({ channel: "msedge" })`, `newPage({ viewport: {width:390,height:844} })`) and measure `scrollWidth - innerWidth` for horizontal overflow. playwright-core 1.48 can't launch this Edge. Server: `npx next start -p 3311` after build.
- 2026-10-31 — PowerShell variables are case-insensitive: `$s` in a loop overwrites `$S`. Use distinct names.
- 2026-10-31 — Review lessons: (1) never use `toISOString().slice(0,10)` for "today" — UTC is a day behind MYT before 08:00; use `isoDate()`. (2) Any list/export query can silently stop at 1000 rows (PostgREST max rows) — use `fetchAll` with a stable order ending in `id`. (3) Every status a workflow can set must have a way back out (removed engines were stuck). (4) Keep counting rules identical in triggers and views (`removed_at >` vs `>=`). (5) Validate post-login `next` with URL parsing, not startsWith.
- 2026-10-31 — Dev overlay "Blocking Route: Next.js encountered the unstable value new Date() while prerendering" (user saw it on /dashboard). Awaiting cookies() first is NOT enough in Next 16.4 (runtime prefetch can prerender with cookies). Rule: never `new Date()` / `Date.now()` / `Math.random()` in server components or route handlers — use `await requestNow()` from `lib/now.ts` (calls `connection()` first). `npm run build` does NOT catch this; only the dev overlay does. Follow-up: supabase-js itself calls `Date.now()` inside `auth.getUser()` (session expiry), flagged at `TopbarUser` in the layout — fixed by `await connection()` at the top of `createClient()` in `lib/supabase/server.ts`, so every server Supabase use is per-request.
- 2026-10-31 — Repeated mistake: chained several `cat <<'EOF'` + `python - <<'PYEOF'` heredocs in ONE Bash call → bash parse error, nothing ran. Rule: create/overwrite files with the Write tool, edits with Edit; only use short heredocs, one per call.
- 2026-10-31 — supabase-js `.rpc(...).returns<T[]>()` mistypes set-returning functions ("Cannot cast single object to array type") — cast the data instead.
- 2026-10-31 — Server components can't sign a user out (cookies are read-only in render): redirect to a route handler (`/logout`) that calls `signOut()` and redirects.
- 2026-10-31 — PGlite tests: JSON.stringify of a Postgres `infinity` timestamp prints null (Invalid Date) — not a bug. To test RLS, `set role authenticated` after granting table privileges (superuser bypasses RLS).

- 2026-10-27 — Stopping the dev server: broad `Stop-Process` over all node processes was blocked. Find the PID with `netstat -ano | grep :<port>` and `taskkill //PID <pid> //T //F`.
- 2026-10-27 — Table cells: put `whitespace-nowrap` on dates and a `min-w-*` on free-text columns, or dates wrap and text squashes.
